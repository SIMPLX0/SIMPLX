# ⚡ SIMPLX - 개발자 커뮤니티 허브 및 정보 사이트

> **"함께 공부하고 자극받으며 성장하는 끈끈한 개발자들의 소통 및 지식 공유 커뮤니티 허브"**
> 
> SIMPLX는 디스코드 생태계를 기반으로 활동하는 개발 아지트이며, 본 프로젝트는 SIMPLX 커뮤니티의 공식 안내 사이트이자 크루 모집, 실시간 인프라 모니터링, 그리고 커뮤니티 소통을 지원하는 프리미엄 포털 웹 애플리케이션입니다.

---

## ✨ 핵심 기능 (Key Features)

### 1. 🌌 몰입감 넘치는 인터랙티브 히어로 섹션
*   **마우스 트래킹 라이트 이펙트:** 사용자의 마우스 커서 움직임에 실시간 반응하는 부드러운 방사형 그라데이션 광원 효과를 제공합니다.
*   **동적 캔버스 점 그리드:** HTML5 캔버스를 활용하여 백그라운드에서 수학적인 사인/코사인 파동 알고리즘을 통한 미세하고 부드러운 도트 그리드 애니메이션을 렌더링합니다.

### 2. 📋 파운딩 크루 채용 관리 (CRUD Panel)
*   **실시간 공고 필터 및 검색:** 전체 공고를 대분류(기술지원팀 / 운영지원팀) 및 소분류(Production, Platform Engineering, Trust & Safety, CS 등)별로 필터링하고 검색어로 상세 조회할 수 있습니다.
*   **디스코드 복사 유틸리티:** 클릭 한 번으로 공고 내용을 디스코드 임베드 스타일(마크다운 블록)로 클립보드에 완벽하게 포맷팅하여 복사할 수 있어 운영진의 커뮤니티 공지 업무 효율성을 극대화합니다.
*   **보안 제어 콘솔 (Admin Node):**
    *   **NFC/QR 모바일 연동 시뮬레이션:** 인터랙티브 QR 코드 스캔 및 터널링 인증 시뮬레이션을 탑재했습니다.
    *   **어드민 인증 관리:** 보안 액세스 키 입력(보안 코드: `simplx2026` 또는 `admin2026`)을 통한 세션 관리로 공고 작성, 수정, 삭제(CRUD)가 완벽하게 동작하는 어드민 권한 제어판을 제공합니다.
*   **부드러운 아코디언 카드:** 각 공고 카드는 확장 및 축소 시 유동적으로 컴포넌트의 실제 높이(`scrollHeight`)를 계산하여 물리 연산에 가까운 리드미컬한 트랜지션을 보여줍니다.

### 3. 🚦 실시간 서비스 상태 대시보드 (Status Page)
*   **인프라 모니터링 시뮬레이터:** 봇 서버, 인증 API, 웹 호스팅, 큐 서비스 등 각 노드의 레이턴시(ping) 및 에러 레이트, 트래픽 추이를 실시간 그래픽 및 차트로 대시보드화하여 보여줍니다.
*   **시나리오 시뮬레이션:** 정상 모드뿐만 아니라 트래픽 급증(DDOS 대응 상황), 긴급 점검, 데이터베이스 순제어 등 다양한 백엔드 상황을 인터랙티브하게 트리거하여 가상의 장애 대응 시연이 가능합니다.

### 4. ✉️ 통합 소통 및 피드백 게이트웨이
*   **디스코드/SNS 다이렉트 소셜 게이트웨이:** 클릭 시 즉각적으로 소통 채널로 연결하는 감각적인 카드 그리드.
*   **커뮤니티 문의 폼:** 다크 테마 디자인과 완벽히 호환되며 유효성 검사가 적용된 피드백 송신 양식.

## 🛠️ 기술 스택 (Tech Stack)

*   **Core:** React 18, Vite (Fast HMR)
*   **Icons:** Lucide React
*   **Styling:** Vanilla CSS (프리미엄 HSL 컬러 토큰 설계, 글래스모피즘, 커스텀 네이티브 변수 및 앰비언트 글로우 스타일)
*   **State & Storage:** React hooks (`useState`, `useEffect`, `useRef`, `useCallback`), `localStorage` 및 `sessionStorage`를 통한 로컬 상태 영속화

## 🚀 시작하기 (Getting Started)

### 📦 설치 (Installation)

로컬 개발 환경에서 프로젝트를 실행하기 위해 종속성 패키지를 설치합니다:

```bash
npm install
```

### 💻 실행 (Development Server)

로컬 Vite 개발 서버를 기동합니다 (기본 포트: 5173):

```bash
npm run dev
```

### 🏗️ 빌드 (Production Build)

최적화된 프로덕션 빌드 번들을 컴파일합니다:

```bash
npm run build
```

## 🔒 어드민 비밀번호 안내

*   **보안 액세스 코드:** `simplx2026` 또는 `admin2026`
*   크루 모집 섹션 내 `어드민` 버튼을 누르고 비밀번호를 입력하거나 QR 코드를 클릭하면 인증 프로세스가 시뮬레이션되어 어드민 권한이 정식으로 활성화됩니다.
